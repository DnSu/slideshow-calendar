HOW TO USE THIS FOLDER
======================

Pictures in this folder are shown on the building's screens.
This text file and the config Doc are never shown on screen; only
pictures are.


1. PICTURES THAT ALWAYS SHOW
----------------------------
Put a picture directly in this folder (not inside another folder)
and it will show all the time, until you delete it.


2. PICTURES FOR CERTAIN DATES
-----------------------------
Make a folder inside this folder, name it with dates, and put the
pictures inside it. The name decides when the pictures show.

  Folder name              Pictures show
  -----------------------  ------------------------------------------
  2026-12                  from now until the end of December 2026
  2026-12-31               from now until December 31, 2026
  2026-12-01 2026-12-31    from December 1 through December 31, 2026

Write dates as YEAR-MONTH-DAY with numbers, for example 2026-03-07
(not 2026-3-7). Put ONE space between two dates. Both dates count:
the pictures show for the whole first day and the whole last day.

You can add a note after the dates to say what the folder is for:
put a space, a dash, a space, then anything you like. The note is
ignored; only the dates count.

  2026-12-01 2026-12-31 - Pool closed
  0000-12-15 0000-01-05 - Winter holidays


3. PICTURES THAT COME BACK EVERY YEAR
-------------------------------------
Use 0000 as the year. Only the month and day matter, so the folder
works every year without being changed.

  Folder name              Pictures show
  -----------------------  ------------------------------------------
  0000-06-15 0000-07-05    every year, June 15 through July 5
  0000-12-15 0000-01-05    every year, December 15 through January 5
  0000-06                  every year, all of June
  0000-11 0000-12          every year, November 1 through December 31
  0000-12-25               every year, December 25 only

Don't mix: "0000-06-15 2026-07-05" will not work.


HOLIDAYS
--------
Make a folder named exactly "Holidays". Inside it, make one folder
for each holiday, named with the holiday's date, and put that
holiday's pictures inside. The pictures show every year, from 7 days
before the holiday through 1 day after it.

  Folder name inside "Holidays"                Holiday
  -------------------------------------------  ----------------------
  July 4 - Independence Day                    July 4
  December 31 - New Year's Eve                 December 31
  Third Monday in February - Presidents Day    3rd Monday of February
  Last Monday in May - Memorial Day            last Monday of May
  Fourth Thursday in November - Thanksgiving   4th Thursday of Nov.

You can write the day as First, Second, Third, Fourth or Last.
Months and days can be written in full or short (Feb, Mon).
Everything after " - " is just a note; it can be left out.

For a holiday season instead of one day, use dates with 0000 as in
part 3, for example "0000-12-01 0000-12-31 - Happy Holidays". Those
show exactly on those dates.

Holiday pictures show before all other pictures.
To change the 7 and 1 days, see "holidays" in part 5.


EMERGENCY OVERRIDE
------------------
A folder named exactly "Emergency Override" is special. While it has
any pictures in it, the screens show ONLY those pictures, and nothing
else: no other pictures, no calendar, no weather. Take the pictures
out (or delete them) and the screens go back to normal. Leave the
folder empty when there's no emergency.

It can take up to about an hour and a half to appear on the screens.
To make it faster, open the website's /slideshow page and press the
Refresh button (the circle arrow): the screens then change within
about 10 minutes.


4. THINGS TO KNOW
-----------------
- Apart from "Holidays" and "Emergency Override", folders with any
  other name are ignored. Nothing in them shows.
  Examples that will NOT work: "December", "2026-13-01",
  "2026-12-31 2026-12-01" (ends before it starts), "12-25".
- Only one level of folders (two inside "Holidays"). A folder inside
  a date folder is ignored.
- Pictures show in name order: holiday pictures first (see
  HOLIDAYS), then loose pictures, then each date
  folder in name order. Number file names to control the order,
  for example 01-welcome.jpg, 02-pool-hours.jpg.
- Use pictures the same shape as the screen (for a tall screen,
  1080 wide by 1920 high). Other shapes are trimmed at the edges
  to fill the screen.
- Use JPG or PNG files. PDFs, videos, Word files, Google Slides and
  shortcuts don't show; save them as a JPG or PNG first.
- To see what's wrong, open the website's /slideshow page. Under the
  picture it lists folder names it doesn't understand, folders with
  no pictures, files that won't show (and why), and mistakes in
  the settings.
- Changes can take up to about an hour and a half to appear.
  If you move or delete a picture, the screens notice when they try
  to show it, skip it, and update their list within a few minutes.
- Old date folders stop showing by themselves. You can delete them
  whenever you like.
- Don't rename the Google Doc called config if there is one.
  It holds the screen settings (see below).


5. SCREEN SETTINGS (the "config" Google Doc)
--------------------------------------------
A Google Doc named exactly config in this folder changes how the
screens behave. If there is none, the screens use their built-in
settings.

To make it: in this folder, choose New, Google Docs, name it config,
and paste in the settings from the website's /slideshow page (the
"Copy fixed settings" button) or from the template that comes with
this guide. Each line looks like this:

  PICTURE_SECONDS = 20

Change the value after the = sign. That's all: no quotes, commas or
brackets. Lines starting with # are notes. Delete a line to use the
built-in value. For on/off settings, write yes or no.

The notes in the Doc explain each setting. The main ones:

  PICTURE_SECONDS            seconds each picture stays on screen (20)
  PICTURE_FIT                cover fills the screen and trims the edges;
                             contain shows the whole picture
  CALENDAR_AFTER_PICTURES    pictures before the calendar shows (5)
  CALENDAR_SECONDS           seconds each calendar page shows (60)
  CALENDAR_TITLE             heading at the top of the calendar
  SHOW_WEATHER               yes or no
  WEATHER_SECONDS            seconds the weather shows (15)
  HOLIDAY_DAYS_BEFORE        days before a holiday its pictures show (7)
  HOLIDAY_DAYS_AFTER         days after a holiday they keep showing (1)

The weather page needs the screen's location, which is set up by
whoever manages the website.

If a line has a mistake, the screens ignore just that line and use
the built-in value, so a typo can't break the screens. The website's
/slideshow page lists any mistakes, and its "Copy fixed settings"
button copies a corrected version, keeping your settings: select
everything in the Doc and paste it over.

Changes take effect within about an hour and a half.

An older file called config.json still works, but only if there is
no config Doc. Use one or the other, not both.

Deleting the config Doc returns everything to the built-in settings.
